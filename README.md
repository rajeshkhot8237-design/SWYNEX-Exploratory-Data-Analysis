# SWYNEX-Exploratory-Data-Analysis
Exploratory Data Analysis using Python, Pandas, Matplotlib and Seaborn.
SWYNEX - Exploratory Data Analysis

Task 2: Exploratory Data Analysis (EDA)

Objective

To analyze the cleaned Iris dataset using Python and identify useful patterns, trends, and correlations.

Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

Dataset

The cleaned Iris dataset contains 149 rows and 6 columns.

Key Insights

1. The dataset contains 149 rows and 6 columns.
2. Average sepal length is 5.85.
3. Average petal length is 3.75.
4. Petal width ranges from 0.1 to 2.5.
5. Petal length and petal width have a strong positive correlation of 0.96.

Visualizations

- Feature distribution histograms
- Correlation heatmap
- Box plots

Conclusion

Exploratory Data Analysis helped identify feature distributions, summary statistics, and relationships between numerical variables.
